# ゲームデザインドキュメント (GDD)

## 1. コンセプト

**タイトル**: English Learning Visual Novel  
**ジャンル**: 恋愛シミュレーション × 英語学習  
**ターゲット**: 18-30歳、CEFR A2-B1レベル  
**プラットフォーム**: Web (将来: PC/モバイル)

## 2. コアループ

```
ストーリー導入
    ↓
セリフ・会話（英語/日本語）
    ↓
選択肢（英語表現を選ぶ）
    ↓
好感度/フラグ変動
    ↓
復習クイズ（SRS）
    ↓
報酬（新規シーン/ギャラリー）
    ↓
次のストーリーへ
```

## 3. 学習要素

### 表現バンク
- 挨拶・自己紹介
- 誘い・約束
- 断り・謝罪
- 感謝・褒める
- 感情表現

### SRS統合
- 選択肢で使った表現を自動的にカード化
- 間隔反復で定着を促進
- クイズ形式: リコール/穴埋め/並べ替え/シャドーイング

## 4. キャラクター

### Emma（エマ）
- 年齢: 21
- 属性: イギリスからの交換留学生
- 性格: 明るく社交的、英語教育に興味
- 好感度システム: 選択肢により±変動

## 5. チャプター構成

### Chapter 1: 初対面
- 場所: 語学カフェ
- 目標: 自己紹介表現の習得
- 学習表現数: 8-10

### Chapter 2: カフェで雑談
- 趣味・好みについて話す
- 目標: 好き嫌いの表現

### Chapter 3: 誘い
- 映画や食事に誘う
- 目標: 提案と受諾の表現

### Chapter 4: 約束
- 日時・場所の調整
- 目標: 予定に関する表現

### Chapter 5: トラブル
- 遅刻や予定変更
- 目標: 謝罪と説明の表現

### Chapter 6: 告白
- 感情の表現
- 目標: 深い感情表現

## 6. UI/UX

### メイン画面
- 背景画像
- キャラクター立ち絵
- ダイアログボックス
- 選択肢リスト
- HUD（好感度、進捗）

### 設定画面
- 言語切替（日本語/英語）
- テキスト速度
- 音量調整
- セーブ/ロード

## 7. 進行システム

### セーブポイント
- 章の終わり
- 重要な選択肢の前
- オートセーブ（常時）

### 分岐
- エンディング: Good/Normal/Bad
- 好感度による分岐

## 8. リワード

- ギャラリー解放（CG、立ち絵差分）
- 実用フレーズカード
- 実績バッジ

## 9. 学習効果測定

### 指標
- 復習正答率
- 表現使用回数
- セッション時間
- 継続日数
